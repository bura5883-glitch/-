# 事業計画書

元手1万円から始める古着販売 × SNS発信

---

## 1. 企画概要

元手1万円から古着販売をスタートし、古着の価値を見極めながら資産を増やしていく過程をSNSで発信する。

安く販売されている古着を仕入れ、適正価格で販売することで利益を積み重ねる。その過程や結果を動画として公開し、SNSでの認知拡大と発信力の向上を目指す。

---

## 2. 事業目的

- 古着販売を通じて利益を生み出す。
- SNSで継続的に発信し、知名度と影響力を高める。
- 発信活動を通じて、今後さまざまな挑戦につながる土台を作る。

---

## 3. 法令・許可

### 3.1 古物商許可

転売目的で中古品を仕入れる営業には古物営業法上の**古物商許可**が必要となる。本企画は「仕入れて売る」ことを前提とするため、**活動開始前に許可を取得する**。

| 項目 | 内容 |
| --- | --- |
| 許可権者 | 神奈川県公安委員会 |
| 申請先 | 営業所所在地を管轄する警察署 生活安全課（防犯係） |
| 申請手数料 | 19,000円（不許可・取下げの場合も返還されない） |
| 標準処理期間 | 土日祝を除き40日程度 |
| 主な必要書類 | 許可申請書 / 住民票 / 身分証明書（本籍地の市区町村が発行）/ 略歴書 / 誓約書 |

無許可営業は3年以下の懲役または100万円以下の罰金。本企画は活動の様子をSNSで公開する構造上、無許可のまま進めることは事実上できない。

**申請時に確認すること**

- メルカリ等のプラットフォームで販売する場合の「ホームページ利用取引の届出」の要否（管轄警察署によって見解が異なるため、申請時に直接確認する）。

### 3.2 許可取得後の義務

- 許可証（標識）を掲示する。
- 古物台帳を備え付ける。
  - 1回の取引額が1万円未満の場合は記載義務が免除される（古着は免除の例外品目に該当しない）。
  - ただし本企画では、週次記録テンプレートの仕入れ明細・販売明細をもって全取引を記録する。

### 3.3 許可費用の扱い

申請手数料19,000円は**仕入れ資金ではないため、元手10,000円ルールの対象外**とする。

この点はコメントで必ず問われるため、初回動画内で明示する。

### 3.4 信頼性への活用

許可番号は公開情報であるため、各SNSのプロフィールに記載する。許可を取得済みであることを明示することで、「無許可の転売」という批判を事前に無効化する。

## 4. 活動内容

### 4.1 仕入れ

元手10,000円のみを使用し、価値に対して価格が安い古着を仕入れる。

**主な仕入れ先**

- フリーマーケット
- セカンドストリート
- トレジャーファクトリー
- オフハウス
- ブックオフSUPER BAZAAR
- リサイクルショップ
- 古着屋

### 4.2 販売

仕入れた商品を適正価格で販売し、利益を積み重ねる。

**主な販売先**

- メルカリ
- セカンドストリート
- フリーマーケット
- その他中古販売サービス

### 4.3 単価方針

メルカリの販売手数料10%に送料を加えると、低単価商品はほとんど利益が残らない。元手10,000円の範囲では、**点数を追わず単価を上げる**方針を取る。

少数を目利きで選ぶスタイルは、後述の発信方針（利益額ではなく目利きを見せる）とも一致する。

---

## 5. 運営ルール

- 元手は10,000円のみとする。
- 追加資金は投入しない。
- 利益のみで運営を継続する。
- 偽物・コピー品は取り扱わない。仕入れ後に偽物と判明した場合も**販売しない**（詳細は 11.2）。
- 自信のないジャンルには手を出さない。
- 商品状態は正確に記載する。
- 手数料・送料を含めて利益を管理する。
- 活動開始前に古物商許可を取得する。

---

## 6. 撮影ルール

炎上・トラブルを避けるため、撮影について以下を厳守する。

### 6.1 店舗

- **店内は撮影しない。** チェーン各店は原則として無断の店内撮影を禁止している。
- 仕入れの様子は撮らず、**店外での戦利品紹介**として構成する。

### 6.2 フリーマーケット

- **買う瞬間は撮影しない。** 販売結果から撮る。
- 個人出品者との取引を撮影対象にしない。第三者が映り込む撮影を避ける。
- **カメラの前で値切らない。**

### 6.3 理由

チェーン店は法人が値付けしているため視聴者の感情移入が起きにくいが、フリーマーケットは個人が値付けしているため、安く買う場面は「個人から巻き上げた」と受け取られやすい。経済的には同じ取引でも、映像としての意味が変わる。

## 8. SNS運用

### 8.1 投稿計画

| プラットフォーム | 投稿頻度 | 投稿内容 |
| --- | --- | --- |
| TikTok | 週2本 | 戦利品紹介 / 販売結果 / 利益報告 / 商品解説 |
| YouTube Shorts | 週2本 | TikTokと同じ動画を投稿 |
| YouTube（ロング動画） | 必要に応じて | 裏側 / まとめ動画 / 特別企画 / 長時間の密着動画 |
| Instagram | 週2本 | TikTokと同じ動画をリールとして投稿 |

### 8.2 発信方針

**フックは「利益額」ではなく「目利き」に置く。**

- ✕「300円→5,000円！」— 搾取の物語として受け取られる
- ○「シングルステッチだから年代が古い。だからこの値段」— 知識の物語として受け取られる

含まれる情報は同じでも、受け取られ方が逆になる。

**手間を可視化する。** 洗い・補修・採寸・撮影・梱包の工程を映す。転売が嫌われる理由は「儲けていること」ではなく「価値を足していないように見えること」にあるため、実際に足している手間を見せる。

## 11. 想定される課題

### 11.1 SNSで再生数が伸びない

**対策**

- 冒頭の構成を改善する。
- タイトル・テロップを工夫する。
- 投稿データを分析し、改善を繰り返す。

### 11.2 偽物を仕入れてしまった

ヴィンテージのリーバイス、ナイキ、バンドT、カーハート等は復刻品・偽物が多く、意図せず仕入れてしまうリスクがある。

**対応**

- **販売しない。** 偽物と知りながらの販売は商標法違反にあたる。
- 購入店舗に返品・返金を相談する。
- **経緯を動画にする。** 損失を隠さず、見分け方の解説としてコンテンツ化する。
- 動画では**購入店舗が特定できる形にしない**。特定の店を名指しすることは、店側とのトラブルにつながる。

**予防**

- 自信のないジャンルは扱わない（運営ルール）。
- コメント欄での指摘は否定せず受け止め、訂正動画で対応する。公開でやっている以上、詳しい視聴者の指摘は精度を上げる資産として扱う。

## 12. 目標と終了条件

### 12.1 目標金額（クリア条件）

**元手10,000円を300,000円にする。**

30倍。この数字を初回動画で宣言し、達成するまでシリーズを継続する。

**想定される到達期間**

| 前提 | 値 |
| --- | --- |
| 販売倍率（販売価格 ÷ 仕入値） | 3.5倍 |
| 売切率（1サイクルで売れる割合） | 80% |
| 1サイクルの期間 | 約7週 |

この前提では**4サイクル・約7ヶ月**で到達する。販売倍率が3.0まで落ちる場合は6〜7サイクル・約10ヶ月。

**単価を上げることが必須条件**

資金は指数関数的に増えるが、**取扱点数も同じ速度で増える**。仕入単価を1,200円のまま固定すると、第4サイクルで104点、第5サイクルで241点を扱うことになり、1人では処理できない。

したがって、資金の増加に合わせて仕入単価を引き上げる。

| サイクル | 仕入単価の目安 | 点数 |
| --- | --- | --- |
| 第1回 | 1,200円 | 8点 |
| 第2回 | 2,000円 | 11点 |
| 第3回 | 3,500円 | 15点 |
| 第4回 | 6,000円 | 21点 |

この方針は 4.3 の単価方針、および発信方針（目利きを見せる）とも一致する。

### 12.2 終了条件（ゲームオーバー）

資金を失って継続できなくなった場合は、隠さず**ゲームオーバーとして公開する**。

**終了条件**

- 現金残高と在庫の評価額が尽き、追加資金なしでは仕入れができなくなった時点。
- 追加資金は投入しない（運営ルール）。

**終了後の企画**

フリーマーケットに出店し、視聴者向けのサービスを行う。

失敗をそのまま出すことは、この企画では損失ではない。元手1万円という設定は、成功も失敗も同じだけ物語になる構造になっている。

---

## 13. 最終目標

**元手10,000円を300,000円にすること**を数値目標とする。

その上で、古着販売を通じて利益を生み出し、その過程をSNSで発信することで知名度と発信力を高める。

継続的な発信を通じて、自分自身の価値を高め、将来的なさまざまな活動や挑戦につながる基盤を作る。
