# 事業計画書

## 企画概要

元手1万円から古着販売をスタートし、古着の価値を見極めながら資産を増やしていく過程をSNSで発信する。

安く販売されている古着を仕入れ、適正価格で販売することで利益を積み重ねる。その過程や結果を動画として公開し、SNSでの認知拡大と発信力の向上を目指す。

## 事業目的

- 古着販売を通じて利益を生み出す。
- SNSで継続的に発信し、知名度と影響力を高める。
- 発信活動を通じて、今後さまざまな挑戦につながる土台を作る。

## 活動内容

### 仕入れ

元手10,000円のみを使用し、価値に対して価格が安い古着を仕入れる。

主な仕入れ先

- フリーマーケット
- セカンドストリート
- トレジャーファクトリー
- オフハウス
- ブックオフSUPER BAZAAR
- リサイクルショップ
- 古着屋

### 販売

仕入れた商品を適正価格で販売し、利益を積み重ねる。

主な販売先

- メルカリ
- セカンドストリート
- フリーマーケット
- その他中古販売サービス

## 運営ルール

- 元手は10,000円のみとする。
- 追加資金は投入しない。
- 利益のみで運営を継続する。
- 偽物・コピー品は取り扱わない。
- 商品状態は正確に記載する。
- 手数料・送料を含めて利益を管理する。

## 活動エリア

- 神奈川県
- 東京都
- 必要に応じて関東近郊

## SNS運用

### TikTok

週2本投稿。投稿内容は、仕入れの様子 / 販売結果 / 利益報告 / 商品紹介。

### YouTube Shorts

TikTokと同じ動画を投稿する。

### YouTube（ロング動画）

必要に応じて投稿する。投稿内容は、裏側 / まとめ動画 / 特別企画 / 長時間の密着動画。

### Instagram

週2本投稿。TikTokと同じ動画をリールとして投稿する。

## 活動スケジュール

| 曜日 | 内容 |
| --- | --- |
| 平日・土曜日 | 商品リサーチ / 仕入れ / 撮影 / 出品準備 |
| 日曜日 | 商品販売 / 結果撮影 / 動画編集 / SNS投稿 |

## 管理項目

毎週以下の内容を記録・管理する。

- 現金残高
- 仕入れ金額
- 販売金額
- 利益
- 手数料
- 送料
- 総利益
- 在庫数
- 投稿本数
- 動画再生数
- フォロワー数

## 想定される課題

**SNSで再生数が伸びない**

対策

- 冒頭の構成を改善する。
- タイトル・テロップを工夫する。
- 投稿データを分析し、改善を繰り返す。

## 最終目標

古着販売を通じて利益を生み出し、その過程をSNSで発信することで知名度と発信力を高める。

継続的な発信を通じて、自分自身の価値を高め、将来的なさまざまな活動や挑戦につながる基盤を作る。
